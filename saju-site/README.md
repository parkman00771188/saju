
## 명리 판정 규칙 (격국 · 신강신약 · 용신)

- **격국** (`src/saju/gyeokguk.js`, 자평진전 취격법): 월지 지장간(여기·중기·정기) 중 년간·월간·시간에 투출한 글자를 격으로 취함(정기 → 중기 → 여기). 비견·겁재 투출은 격으로 취하지 않음. 子午卯酉월은 투출과 무관하게 정기. 辰戌丑未월은 투출이 없고 중기가 다른 지지와 삼합이면 중기. 그래도 없으면 정기. 비견 → 건록격, 겁재 → 양인격(양간)·월겁격(음간).
- **신강신약** (`interpret.js#strength`): 일간을 돕는 오행(비겁·인성)의 가중 비율. 월지 3(득령, 약 30%) · 일지 1.5 · 년지/시지 1 · 월간 1.2 · 년간/시간 1. 50% 이상 신강, 40% 미만 신약, 그 사이 중화.
- **억부용신** (`src/saju/yongshin.js`): 신강 → 식상·재성·관성이 좋은 편(비겁 원인: 관성>식상>재성, 인성 원인: 재성>식상), 비겁·인성이 나쁜 편. 신약 → 인성·비겁이 좋은 편(관성 병: 인성, 재성 병: 비겁, 식상 병: 인성), 식상·재성·관성이 나쁜 편. 희신 = 좋은 편에서 용신을 낳는 기운, 기신 = 균형을 깨뜨린 원인(병) 그룹, 구신 = 나쁜 편에서 기신을 낳는 기운, 한신 = 나머지. 중화 → 조후 기운을 용신으로 삼고 생·극 순환으로 희기신.
- **조후용신** (`patterns.js#CLIMATE_NEED`): 궁통보감 요지를 10 일간 × 4 계절로 요약(예: 봄 壬癸 → 金, 봄·가을 丙 → 水, 겨울 대부분 → 火, 여름 대부분 → 水).
- **자주 묻는 질문** (`src/saju/faq.js`): 해석 결과(연·월 운 점수, 대운, 신살, 관계 플래그)에서 14개 질문의 답을 생성 — 올해 흐름, 연애·결혼·재물·취업·도전 시기, 직업, 삶의 방향, 장단점, 조심할 시기, 상승기, 강점, 이사운, 함께하면 좋은 사람. 시기 질문은 추천 연도마다 "좋은 달 + 이유(관성·인성·식상·배우자 별·도화·일지 합·조후·용신)"와 피할 달을 연도 카드로 표시. 책 마지막 페이지의 아코디언.
- **개운법 상세** (`src/saju/gaeun.js`, `deep.js#YONG_DETAIL/CLIMATE_OPEN/STRENGTH_OPEN/GROUP_OPEN/SAL_REMEDY/OPEN_BY_STEM`): 용신 채우기(색·방향·숫자·요일·시간대·소지품·공간·활동·마음가짐), 기신 줄이기, 조후 보완, 올해 개운 달력(용신·조후·기신 달 + 요일·일진 루틴), 신살별 처방, 신강신약·격국·십성 습관, 오행 균형, 일간별 맞춤 조언.
- **운과 원국의 관계** (`src/saju/unrel.js`): 대운·세운·월운 기둥마다 원국과의 천간 합(화기)·충, 지지 육합·반합·삼합/방합/삼형 완성·충·형(삼형·상형·자형)·파·해·원진·귀문, 지장간 통근·암합·암충을 계산. 만세력 카드에 요약 태그(일충·월합 등), 선택 카드 아래 접이식 상세 패널.
- FAQ 연도 추천 규칙: 올해·내년·내후년에서 먼저 고르고(점수 ≥3, 근거 있음, 삼재·일지 충 등 주의 가중 <1.2), 2개 미만이면 그 뒤 연도로 확장하며 "가까운 3년 밖" 표시. 올해는 지난 달을 제외한 남은 달 기준.
- **사건의 형태 서술** (`src/saju/events.js`): 운 글자의 십성 그룹 × 영역(직장·금전·연애·도전)별 사건 템플릿에, 원국의 부족/과잉(십성 레벨 무·중·강), 일지/월지 충, 합·삼합, 역마·지살, 도화, 공망, 조후·용신·기신을 덧붙여 "언제(절입 기준 기간) 무엇이 왜 어떤 모습으로" 문장을 만든다. 천간=겉·초반(세운은 상반기), 지지=속·중순 이후(하반기) 규칙 적용. FAQ 연도 카드의 달마다, 카테고리 페이지 선택 연도의 상위 2개 달에 표시.
- FAQ 시기 질문은 올해·내년·내후년 세 해를 항상 카드로 보여 주고(각 해의 좋은 달·이유·사건), 세 해가 모두 약하면 뒤 연도 하나를 참고로 덧붙인다. 아코디언은 기본 접힘·한 번에 하나만.
- **이 사주만의 포인트** (`src/saju/personal.js`): 직장·금전·연애·건강·학업마다 실제 글자·자리·개수·관계로 문장을 만든다 — 해당 십성이 놓인 자리(년/월/일/시 × 간/지, 지장간), 정관/편관·정재/편재 혼잡, 관인상생·재생관·상관견관·식신제살·식상생재·군겁쟁재·재다신약·재고 같은 구조, 해당 자리의 12운성·신살·공망, 자리 간 충·형·파·해·원진·귀문·합, 용신/희신/기신 그룹과의 관계, 전문가 의견(그 사주의 조합 키에 대한 주장 라벨 상위)과 현재·다음 대운 점수. 카테고리 페이지 상단과 FAQ 답 첫 문단에 표시.
- **KB 라벨 확장** (`analysis/build_kb.py`): 개념 124(격국 10·육친 5·직업군 11 추가), 패턴 255(자리×십성 40, 십성 운 10 추가), 사건 라벨 102(직장·금전·연애·건강·학업·가족 추가). 해석의 전문가 의견 키에 격국·자리별 십성·현재 대운 십성 운을 추가.
- **약한 고리 ↔ 운의 보완/악화** (`src/saju/dynamics.js`): 원국에서 조후 부족, 신강/신약 불균형, 없는 십성, 과다 십성(3자리↑), 자리 간 충·원진·형·귀문(같은 글자 쌍은 병합), 공망, 관살혼잡(합거 천간), 상관견관, 군겁쟁재를 '약한 고리'로 추출하고, 대운·세운·월운마다 오행·십성 그룹·합(충을 묶는 합, 합거)·충 반복을 대조해 helps/hurts/mixed를 계산. 책의 "타고난 약한 고리와 그것을 채워 주는 운" 페이지(고리별로 채워 주는 대운·해 / 도드라지는 대운·해), 각 운 페이지 "지금 흐르는 운", FAQ 연도 카드, 월별 사건 문장에 반영.
- 개인 맞춤 문장은 `personal.js`가 영역별 섹션(회사·직함 글자 위치 → 글자들이 만나는 모습(합·충·형·파·해·간여지동·12운성·신살·공망) → 전문가들이 자주 짚는 이야기)으로 만들어 기존 섹션 사이에 배치하며, 명리 용어는 처음 나올 때 쉬운 말로 풀어 쓴다.
- **신강·신약 프로필** (`src/saju/strengthProfile.js`): 원인별 7유형(비겁 신강·인성 신강·관성 신약·재성 신약·식상 신약·기본 신약·중화)으로 성격·강점·조심할 점·생활(직장·금전·연애·건강)·팁을 서술하고, 받쳐 주는 글자와 비율(%), 원인 글자, 용신으로 개인화. 용신 페이지 "나의 힘", 종합 카드, FAQ 장단점, 각 운의 개인 섹션("○○ 사주의 △△ 특징")에 반영.
- **전문가 이야기 종합 서술** (`src/saju/expert.js`): 영역별 주장 라벨을 좋은 흐름/조심할 흐름으로 나눠 풀이하고, 각 이야기가 이 사주에서 힘을 얻는 근거(관살혼잡·관인상생·일지 충·도화·역마 등 구조 사실과 연결), 실천 조언, 함께 쓰는 말과 관련 강의 규모를 문단으로 쓴다. 각 운 페이지에서 "글자들이 만나는 모습" 앞에 배치.
- **전문가 이야기 순위 = 문서 수 × 리프트 × 키 특이도** (`interpret.js` evidenceByCat): 리프트는 "그 글자 강의에서 라벨이 나온 비율 ÷ 전체 개념 평균 비율"(`build_kb.py`가 `claims`의 4번째 값과 `meta.claim_base`로 저장, 표본이 작은 개념은 기준율 쪽으로 수축). 어떤 사주에나 나오는 흔한 이야기(연애·만남, 자식 인연 …)는 내려가고 그 글자에서 유독 자주 나오는 이야기가 올라온다(리프트 <0.9는 뒤로). 키 특이도: 일주 2.0 · 일간 1.5 · 격국/월지·일지 십성/일간×십성 1.2 · 오행 과다·결핍/구조 1.0 · 신살·신강신약·자리 십성·대운 0.7. 화면에는 "다른 사주보다 N배"(5배 이상은 상한 표기)로 보여 주고, "사주 전문가들이 말하는 나"·吉/凶 요약은 영역당 2개까지 골고루 뽑는다. 출처는 기여도 순으로 "○○(n회)".
- **LLM 지식 색인 층** (`analysis/extract_knowledge.py` → `analysis/knowledge/**.json` → `build_knowledge.py` → `public/kb_claims.json`, 앱 로더 `src/saju/claims.js`): 영상마다 Gemini(thinking high)가 뽑은 "조건→결과" 주장(결과 문장·라벨·극성·시기·조언·원문 인용)을 조건 키(일간·일주·띠·월지/일지 지지·위치 십성·십성 그룹 과다/없음·신살·오행·격국·신강약·구조·합충·12운성·대운 십성/간지·나이·성별·계절)와 짝 키(`A&B`)로 집계. `interpret.js` 는 키에 LLM 항목이 있으면 그것을, 없으면 정규식 통계(0.3배로 맞춤)를 쓰고, 짝 키는 1.8배, 나이·성별·계절은 짝으로만 쓴다. 행에는 실제 결과 문장(outs)·인용(quotes)·조언이 붙어 `expert.js` 문단("전문가들은 이 조합을 두고 「…」 같은 이야기를 해요. 한 강의(채널 · 제목)에서는 「…」라고 했어요")과 `Evidence` 카드에 표시된다. 연도가 걸린 주장은 `Y2026`·`Y2026&조건` 키로 분리해 "올해와 이달" 페이지의 **전문가들이 말하는 올해의 나**(시기 배지)에만 쓴다. 색인은 번들 밖(public)에 두고 앱 시작 시 내려받아 로드 후 재해석한다. 정리본은 `analysis/knowledge_digest.md`, 구조 설명은 `analysis/knowledge/README.md`.
- **지식 베이스 표시 원칙**: 강의 원문 인용(구어체)과 출처(채널·영상 제목·"누가 말했다")는 화면에 쓰지 않고, 정리된 결과 문장(outs, 끝 마침표 제거·유사 문장 중복 제거)·시기·조언만 쓴다. 표시 위치: ① 각 운 페이지 "사주 전문가들이 자주 짚는 이야기"(좋은/조심 흐름 각 2개는 결과 문장 3개+시기+조언, 나머지 라벨은 "그 밖에 자주 나오는 이야기"로 한 줄씩) ② "사주 전문가들이 말하는 나" 카드(결과 문장 4개+조언) ③ 같은 페이지 **글자별로 정리한 전문가 이야기**(`glyphNotes`: 내 키마다 상위 4개 라벨의 결과 문장, 리프트·시기 배지)와 **두 조건이 겹칠 때만 나오는 이야기**(짝 키) ④ "올해와 이달"의 전문가들이 말하는 올해의 나(`yearClaims`) ⑤ FAQ 연도 카드의 "전문가들이 이 해에 짚는 것"(`yearClaimsFor`)과 각 달의 "전문가:" 문장(`monthExpert`, `Y2026-5&내 글자` 짝 키).
- **쉬운 문장·어투 다양화**: `analysis/easy_outs.py` 가 색인에 실리는 결과 문장·조언(약 6,700개)을 Gemini(thinking low, 약 $0.8)로 일반 사용자용 해요체 한 문장으로 다시 써 `analysis/easy_outs.json` 에 캐시하고, `build_knowledge.py` 가 앱 JSON 에만 적용한다(다이제스트는 원문 유지; 새 문장은 재실행 시 추가분만 처리). `expert.js` 는 도입·좋은 흐름·조심할 흐름·근거·조언·배수·시기 문구를 각각 3~4가지 변형 중에서 영역+라벨 조합의 결정적 해시로 골라 쓴다 — 같은 사주는 항상 같은 문장, 다른 사주·다른 영역은 다른 문장. 조사는 GA/EUN/EUL/IRANEUN 으로 맞춘다.

- **ASR 오탈자 교정** (`analysis/asr_fixes.py`, 채굴 `mine_asr.py`): 자동자막의 명리 용어 오탈자(감목→갑목, 겁제→겁재, 일관→일간, 하주팔자→사주팔자, 귀문관사→귀문관살, 도와쌀→도화살, 조우→조후, 배운/대우→대운 …)를 문맥 조건 정규식 76개로 교정한 뒤 분석. 적용 통계는 `analysis/asr_report.txt`. 구어체 오행(불·물·나무·쇠·흙 많다/없다)도 과다·결핍 개념으로 인식.
- **신년운세 콘텐츠** (`build_kb.py#analyze_years` → `kb.years`, 앱 `src/saju/yearExpert.js`): 제목에 연도·신년이 있는 강의를 일간별·띠별·일주별·전체 키로 묶어 주장 라벨과 월별(절기 아닌 달 표현) 타임라인을 추출. 사용자의 일간·띠·일주에 맞는 콘텐츠를 올해 페이지("사주 전문가들이 말하는 2026년"), FAQ 올해 흐름, 각 운의 "지금 흐르는 운(세운)"에 반영. 개인 키를 우선하고 전체 운세는 보조 가중.
- **자막 원문 정제** (`analysis/clean_transcripts.py`): `asr_fixes.py` 규칙을 `data/` 자막에 제자리 적용(여러 번 실행해도 결과 동일, `--check`로 미적용 여부 검사, `--audit-head`로 Git 원문 대조 보고서). 특수 케이스는 영상 ID 기준으로 손질. 과교정 점검: 관용구(심금을 울리다·일제강점기·일제히·미투 운동·오아시스·연지곤지·정제된)는 보존. 정제 후 `mine_asr.py`로 잔여 후보를 재채굴해 누락(사주 발자·연주 고립·개수도 등)을 규칙에 반영.
- **자막 원문 LLM 교정** (`analysis/rewrite_transcripts.py`, Gemini `gemini-3.8-flash`, 키는 루트 `.env`의 `GEMINI_API_KEY`, git 제외): 규칙으로 못 잡는 문맥 오탈자(구사들이→94년생들이, 개핵→계해, 안타라→형태라, 생령을심→생년월일시 …)를 파일 단위로 교정해 `data/` 원문을 덮어쓴다. 짧게 끊긴 자막 줄을 문장·문단으로 정리하고 [음악] 태그·군말을 제거하되 요약·의역 금지(공백 제거 길이비 0.55~1.35, 한글 비율 검증 실패 시 원문 유지 → `partial`). 7,000자 단위 분할(직전 조각 끝 300자를 참고 문맥으로), 429/5xx 지수 백오프, `analysis/rewrite_manifest.json`에 파일별 해시를 기록해 중단 후 재실행하면 미처리분만 이어서 처리. 헤더(제목·ID·URL)는 그대로 두고 본문만 바꾼다(제목은 채널 운영자가 쓴 원문이라 교정 대상이 아님). 교정 전 원문은 git 이력에 있음.
- **전문가 발언 다이제스트** (`analysis/build_digest.py` → `saju-site/public/kb_digest.json`, 앱 `src/saju/digest.js`): 정제된 자막에서 키(일간·일주·십성·격국·신살·구조·오행·자리×십성·십성 운·신년운세)별로 실제 발언 문장을 고른다 — 필러·홍보·인사·상담 질문·1인칭 일화·연예인 언급·지시어 문장 제외, 서술형 종결만, 희귀 토큰 비율(ASR 잡음)·나열 문장 제한, 키 용어 뒤 조사/서술 근접, 주장·영역 키워드 점수, 근사 중복 제거. 생성만 하고 화면에는 표시하지 않음(구어체 인용 블록은 제외하기로 함). `src/saju/digest.js` 로더는 필요 시 재사용.
