입구는 검정 바탕에서 命이 나타난 뒤 입력으로 전환한다. 모션 줄이기를 지원하고 건너뛰기를 제공한다. 계산 설정은 접어 두고, 결과는 쉬운 풀이를 먼저 보여준다. 만세력·오행·합충·대운 표는 별도 보기로 유지한다. 기존 ReadingOverlay/interpret의 정형 길흉 문구는 새 화면에서 사용하지 않는다.

## 새 해석 규칙

1. 월지의 계절을 바탕으로 천간·지장간의 화/수 비중을 더한다. 월주에 1.6, 나머지 자리에 1의 가중치를 둔다. 지장간 본기에는 0.7, 나머지에는 합계 0.3을 분배한다. 단일 지장간에는 본기 가중치만 적용한다.
2. 계절 온도 기준은 봄 0, 여름 2.5, 가을 -0.5, 겨울 -2.5이며 화 가중합×0.7을 더하고 수 가중합×0.65를 뺀다. -1.2 미만은 온기, 1.2 초과는 냉각을 보완 주제로 삼고, 그 사이는 특정 오행을 필수로 지정하지 않는다. 물리적 온도나 정통 용신 판정이 아닌 서비스 편집 기준이다.
3. 원국의 자리, 선택 연도에 해당하는 대운, 해, 달을 함께 넣어 천간합·천간충·육합·지지충·삼합·방합을 확인한다. 연도 설명에는 해당 해 글자가 포함된 관계만, 월 설명에는 해당 월 글자가 포함된 관계만 표시한다. 삼합·방합은 서로 다른 세 지지가 갖춰져야 한다. 합화는 확정하지 않고 원국의 오행을 변경하지 않는다.
4. 월주와 충하면 업무 환경 조정 가능성을 설명한다. 일지 연결은 가까운 관계의 생활 방식과 연결한다. 들어오는 기운을 일간 기준 십성 역할로 풀되, 받쳐 주는 기운이 적고 책임 기운이 들어오면 업무 부담도 함께 설명한다.
5. 월 추천은 계절 보완(+2), 주제 역할(각 +0.7), 보완 삼합/방합(각 +0.6), 반대 기운(-0.8), 충(각 -0.4), 반대 삼합/방합(각 -0.6), 책임 부담(-0.6)을 비교하는 내부 정렬이다. 해와 대운에 이미 보완 기운이 겹치면 월의 보완 가산은 +1로 낮춘다. 성공 확률이나 길흉 점수로 표시하지 않는다. 일정 차이가 미미하면 추천을 생략한다. 현재 해는 현재 달 이후에서 고른다.
6. 달마다 중순의 절기 월주를 구하고 실제 절입부터 다음 절입 직전까지 표시한다. 라이브러리의 UTC+8 절입 시각에 1시간을 더해 한국 시간을 표기한다. 1월은 전년도 간지로 연결한다.
7. 빈도·긍정어 통계를 개인의 길흉 근거로 쓰지 않는다. 질병·사고·수익·결혼 성공을 예측하지 않는다. 생활 탭은 일상의 리듬으로 구성한다.

## 범위와 검증

전체 자막을 실시간 검색하는 RAG/LLM 상담 기능이 아니라, 검토한 맥락을 코드에 반영한 설명형 규칙 엔진이다. 격국·종격·합화의 모든 학파 조건, 형·파·해의 복합 해석은 새 추천 엔진에 포함하지 않았다. 기초 만세력의 기존 동지/야자시/지역 보정 관행은 유지했다.

`npm test`: 겨울 원국 + 화 세운 + 월지 충의 혼합 해석, 삼합 완성/중복 배제, 합 결과 후보, 날짜 오류, 윤년, 시간 모름, 1월 간지, 12월 절입의 연도 넘김, 15개 연도·주제 조합, 대운 시작 전 처리.

로컬 Chromium에서 데스크톱·모바일 입력, 결과, 주제/연/월 변경, 전문 화면 전환, 입력값 유지, 시간 모름, 잘못된 날짜 피드백, 모션 줄이기를 확인했다. 화면을 캡처해 여백과 줄바꿈을 검토했다. 내장 브라우저는 환경 연결 오류로 사용할 수 없어 임시 경로의 Playwright와 설치된 Chromium으로 검증했다.
